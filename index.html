    데이터 소스
    
      
    
        
    
          
    DEM (지형 고도) — OpenTopography REST API
    
          
      
            
    • 완전 무료, 비학술 사용자 기준 하루 50회 요청 제한
      • 
            
    • bbox 좌표를 넘기면 실시간으로 GeoTIFF를 반환 (별도 다운로드/캐싱 불필요)
      • 
            
    • 데이터셋: SRTM GL1 / Copernicus GLO-30 / ALOS World 3D / NASADEM
      • 
          
    
          
    
            한국 지역은 전부 30m 해상도가 상한선입니다.
            여기서 "30m 해상도"는 격자 한 칸의 가로×세로 크기, 즉 표본 촘촘함의 문제입니다.
            리샘플링(보간)으로 부드럽게 보이게 할 수는 있어도 실제 정밀도는 30m급 그대로입니다.
            OpenTopography가 1m급 LiDAR를 제공하는 지역은 미국(USGS 3DEP), 노르웨이·핀란드·스위스·리히텐슈타인, 뉴질랜드 등 일부뿐이며 한국은 해당하지 않습니다.
          
    
        
    
        
    
          
    건물 — VWorld WFS
    
          
      
            
    • 인증키 발급 필요 (vworld.kr)
      • 
            
    • 지적경계, 도로 레이어는 이번 학습 범위에서 제외 (추후 확장 가능)
      • 
          
    
          
    
            브라우저에서 직접 호출이 불가능합니다.
            VWorld WFS 응답에는 CORS 허용 헤더(Access-Control-Allow-Origin)가 없어, 키와 도메인 등록이 올바르더라도
            프런트엔드 JS의 fetch 호출은 항상 차단됩니다 (서버 간 호출만 전제된 API). 실제 데이터를 받으려면
            지오프로세싱 백엔드가 VWorld 호출을 대신 수행하는 프록시 역할까지 겸해야 합니다.
          
    
        
    
      
    
      
    
        국내 정부 채널(국토정보플랫폼, VWorld 3D 원자료 API)은 실시간 API 부재 또는 2019년 보안규정에 따른 폐쇄로 이번 프로젝트에서 제외했습니다.
